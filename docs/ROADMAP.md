# Milestone status

## Campaign adventure · version 0.4

Twelve chapters contain six stages each. The campaign adds three physical fixtures, four two-phase cores, eight special puzzle finales and in-run rune choices. A separate v2 profile migrates legacy access and archives previous records. See [the release guide](ADVENTURE.md).

## Slice 1 — delivered playable proof

- Two original handcrafted stages with tested winning routes.
- Real deterministic orb collisions, visible delayed conductor circuits, mirrors and armor.
- Three shields, advancing hazards, finite salves, victory/defeat/retry, score breakdown.
- Responsive German and English interface, original vector art and rendered chapter artwork, accessible pointer/keyboard controls, pause.
- Local completed-stage progression, records, synthesized audio, mute, contrast/reduced-effects settings.
- Cloudflare preview on the requested domain and source in the requested repository.

## Current limits

The tutorial can be solved very quickly; this demonstrates the first satisfying chain and is not a 1–3 minute balanced campaign run. Only completed-stage checkpoints persist: refresh does not restore in-flight orbs. Saves are device/browser-local, editable and unsuitable for public competition. The current build intentionally has no server account, entitlement, payment or leaderboard placeholders.
