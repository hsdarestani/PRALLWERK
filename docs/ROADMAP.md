## Current limits

The tutorial can be solved very quickly; this demonstrates the first satisfying chain and is not a 1–3 minute balanced campaign run. Only completed-stage checkpoints persist: refresh does not restore in-flight orbs. Saves are device/browser-local, editable and unsuitable for public competition. The current build intentionally has no server account, entitlement, payment or leaderboard placeholders.
